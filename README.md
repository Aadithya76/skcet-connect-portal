# SKCET Gateway

Build a premium, formal, modern landing page for a college digital application for Sri Krishna College of Engineering and Technology (SKCET), Coimbatore.

This is an app landing/login entry screen, not a traditional college website.

I will upload:

The official SKCET logo

A college campus background image

Use both assets exactly as provided.

The background image should be transformed into a subtle cinematic video-style background experience with slow, elegant motion/parallax/zoom so that it feels like a moving background rather than a static image. Do not make the movement distracting.

Overall Design

The landing page should feel:

Formal

Premium

Elegant

Modern

Professional

Trustworthy

Minimal

Think of a premium university digital portal combined with a modern enterprise application landing page.

Do NOT make it look like a generic college website.

Do NOT add unnecessary sections, cards, statistics, testimonials, navbar, footer, about section or campus information.

The entire page should focus on introducing the application and allowing the user to authenticate.

Full-Screen Background

Create a 100vh full-screen background using the uploaded SKCET campus image.

Simulate cinematic motion using subtle:

slow zoom

parallax movement

gentle position animation

very slow scale transformation

The motion should be almost imperceptible and elegant.

Add a dark translucent overlay over the background so the foreground content remains highly readable.

Use a subtle combination of:

deep navy overlay

black transparency

slight blue tint

Do not heavily blur the campus image.

The campus should remain recognizable and visually attractive.

Centered Hero

Place the entire main content in the center of the screen.

At the top of the content:

SKCET LOGO

Use the uploaded official logo.

Do not recreate, modify, distort or crop the logo.

Maintain the original aspect ratio.

Give the logo enough breathing room.

Below the logo, add a refined application title:

SKCET Digital Campus

Below that, add a small elegant description:

One connected experience for your academic and campus journey.

Keep the text concise.

Do not add large paragraphs.

Typography

Use premium formal typography.

Prefer:

Manrope
or
Plus Jakarta Sans

Use a strong modern font weight for the application title.

Use elegant letter spacing and excellent hierarchy.

The typography should feel like a premium enterprise application rather than a college brochure.

Suggested hierarchy:

Application title:
large, bold, sophisticated

Description:
smaller, light/medium weight

Buttons:
medium/semibold

Avoid decorative or playful fonts.

Authentication Actions

Place two prominent authentication buttons directly below the description.

Primary Button

Login

Design:

Premium navy/blue background

White text

Slightly rounded corners

Elegant shadow

Subtle hover glow

Smooth scale/opacity transition

Comfortable padding

This should be the primary CTA.

Google Button

Continue with Google

Design:

White or slightly translucent background

Official Google G icon

Dark text

Thin subtle border

Slight shadow

Smooth hover transition

The Google button should look equally polished but visually secondary to Login.

Both buttons should have the same dimensions and alignment.

Login Interaction

When the user clicks Login, open a premium authentication modal rather than navigating to a plain-looking page.

The background image/video-style animation should remain visible behind the modal but become darker.

Create a centered authentication card.

Login Modal

Use:

20–24px rounded corners

premium spacing

subtle glass/blur effect

soft shadow

clean white/translucent surface

elegant entrance animation

At the top:

SKCET logo

Heading:

Welcome Back

Subtitle:

Sign in to continue to SKCET Digital Campus.

Fields:

Email Address

Password

Below the fields:

Remember me
and
Forgot password?

Primary button:

Login

Then a subtle divider:

OR

Then:

Continue with Google

Add a small close button in the top-right corner.

Modal Animation

When Login is clicked:

fade background slightly darker

blur the background subtly

modal scales from approximately 95% to 100%

fade in smoothly

When closing:

reverse the animation smoothly

Allow:

clicking outside the card to close

Escape key to close

Do not use excessive animation.

Everything should feel refined and intentional.

Color Palette

Derive the visual identity from the SKCET logo.

Use:

Deep Navy: #071F4D

Primary Blue: #0B3A82

Royal Blue: #1261B0

Gold Accent: #F9B900

White: #FFFFFF

Dark Text: #101828

The interface should primarily use navy, blue, white and subtle gold accents.

Gold should be used sparingly for small highlights, borders, hover accents or tiny visual details.

Do not create a page filled with bright colors.

Background Treatment

The uploaded campus image should remain the visual centerpiece.

Use a layered background treatment such as:

Campus Image
+
Dark Navy Gradient
+
Subtle Blue Tint
+
Very subtle cinematic motion

The foreground content should remain highly readable without hiding the campus completely.

Visual Composition

The final desktop screen should approximately read as:

             SKCET LOGO

          SKCET Digital Campus

   One connected experience for your
      academic and campus journey.

            [ Login ]

      [ Google Icon  Continue with Google ]


The content should remain centered vertically and horizontally.

Do not place the UI too close to the edges.

Use generous whitespace.

Responsive Design

Desktop:

Full-screen cinematic campus background

Large centered logo

Elegant centered authentication actions

Tablet:

Maintain visual hierarchy

Reduce logo and heading size slightly

Mobile:

Maintain full-screen background

Center logo and content

Buttons should be large enough for comfortable touch interaction

Login modal should fit naturally within the viewport

Prevent horizontal scrolling

Micro-interactions

Use subtle premium interactions:

Login button:

slight upward movement on hover

subtle shadow increase

smooth transition

Google button:

slight elevation on hover

Logo:

very subtle fade/scale entrance when page loads

Hero content:

smooth fade-in on initial load

Background:

very slow cinematic movement

Do not use flashy effects.

Important Restrictions

Do NOT add:

navbar

footer

About section

campus information

statistics

testimonials

feature cards

unnecessary icons

scrolling sections

scroll indicator

excessive gradients

excessive glassmorphism

stock illustrations

fake information

fake statistics

This is a single-screen premium authentication landing page.

The user should immediately understand:

This is the official SKCET digital campus application.

The visual experience should communicate:

Prestige + Trust + Education + Technology + Simplicity

Make the final result look like a professionally designed modern application from a high-end product design team, while maintaining the formal identity of Sri Krishna College of Engineering and Technology (SKCET).
